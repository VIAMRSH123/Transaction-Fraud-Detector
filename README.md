# Fraud Detection in Digital Payments (UPI / Cards)

A machine learning based fraud detection system developed to identify suspicious digital payment transactions using anomaly detection and classification techniques.

## Problem Statement
Digital transactions such as UPI, debit cards, and credit cards are vulnerable to fraud. This project detects fraudulent behavior automatically.

## Algorithms Used
- Isolation Forest (Unsupervised Anomaly Detection)
- Random Forest Classifier (Supervised Classification)

## Features
- Detects suspicious payment records
- Fraud vs Legit visualization
- Precision, Recall, F1-score evaluation
- Combined fraud decision logic

## Libraries
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Custom transaction dataset with legitimate and fraudulent transactions.

## Run
python fraud_detection.py
